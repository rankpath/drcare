คู่มือและขอบเขตการใช้งาน

    

      เริ่มต้นอย่างไร?
      
กรอกข้อมูลตัวอย่าง ตรวจสอบ Payload แล้วกดจำลองการส่ง
         รายการจะปรากฏในตารางด้านล่าง

    

    

      ส่งข้อความจริงหรือไม่?
      
ไม่ส่งจริง เว็บไซต์นี้ไม่มีการเชื่อม Make, Claude หรือ LINE API
         ผลสำเร็จเป็นสถานะจำลองเท่านั้น

    

    

      ข้อมูลถูกเก็บไว้หรือไม่?
      
ข้อมูลฟอร์มและรายการอยู่ในหน่วยความจำของหน้า
         เมื่อโหลดหน้าใหม่ ข้อมูลจะเริ่มต้นใหม่
         ไม่มีฐานข้อมูลหรือบัญชีผู้ใช้ใน Demo นี้

    

    

      พร้อมใช้กับงานคลินิกจริงหรือยัง?
      
ยังเป็น Demo การใช้งานจริงต้องเพิ่มระบบผู้ใช้ สิทธิ์เข้าถึง
         การจัดเก็บข้อมูล และการยืนยันสถานะจากแต่ละบริการ
         DrCare Dashboard ไม่ใช่เครื่องมือวินิจฉัยโรค
